# Élévation

Trois ombres, trois utilitaires, un sens chacun.

<Shadows />

Une ombre dit « ceci flotte au-dessus ». Un élément posé dans le flux n'en a pas.

Le thème contrasté les annule **toutes les trois** (`none`). Un composant qui compte sur
son ombre pour se distinguer du fond est donc cassé sur ce thème : la bordure fait le
travail, l'ombre le confirme. C'est vérifiable en deux clics dans la barre d'outils, et
c'est la raison principale pour laquelle ce catalogue porte un sélecteur de thème.

Le dégradé de surface disparaît lui aussi sur ce thème, qui tient sa lisibilité de surfaces
strictement plates.
