# Ce qui est arrêté

Vingt-six écrans, clair et sombre. Les dix-neuf tours qui y ont mené ont été supprimés le
2026-10-13, une fois le portage fusionné : ils ne servaient qu'à choisir, et une planche
périmée se confond vite avec la bonne. Le raisonnement, lui, est conservé — dans le
[README](../README.md) du dossier et dans [lieux.md](../lieux.md).

|---|---|
| `01-colonne-fils` | le lieu *Fils* : *Sans projet* en tête, puis les projets en groupes |
| `02-zone-projets` | la zone basse du lieu *Projets* : le projet ouvert déplié, les autres en lignes |
| `03-zone-deux-projets` | deux projets dépliés — le dépli est un état du compte |
| `04-zone-dix-projets` | dix projets repliés, une ligne chacun |
